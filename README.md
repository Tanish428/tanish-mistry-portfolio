# Tanish Mistry — Developer Portfolio

A modern, dynamic personal portfolio and content management platform built using the MERN stack.

## Overview

This project aims to create a professional developer portfolio that showcases technical skills, projects, academic background, experience, and achievements.

Unlike a traditional static portfolio, this application includes a dedicated administration system that allows the owner to manage website content without modifying source code or redeploying the frontend for ordinary content updates.

## Technology Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- RESTful APIs

### Database
- MongoDB
- Mongoose

### Media Management
- Cloudinary

### Authentication and Security
- JWT
- bcrypt
- Helmet
- CORS

## Core Features

- Dynamic personal profile management
- Project management and publishing
- Technical skills management
- Education and experience management
- Achievements and certifications
- Dynamic homepage section management
- Admin dashboard and secure authentication
- Image and resume uploads
- Contact form and message management
- Light and dark theme
- GitHub and LeetCode activity integration
- SEO and website configuration
